# PaperSmith server

The API behind [PaperSmith](https://rohith-kumar-ss.github.io/papersmith/), a research mentor that writes your paper from
your own material. Deployed on Render; sign-in and storage are on Supabase.

Start command: `uvicorn papersmith.api:app --app-dir backend --host 0.0.0.0 --port $PORT`
